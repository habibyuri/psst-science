Privacy policy: Psst Uploader

Last updated: 18 October 2026

What the app is

Psst Uploader is a private tool used only by the owner of the YouTube channel Psst Science (@psstscience) to manage that channel. It uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What data it uses

  • With the owner's permission, it signs in to the owner's own YouTube channel through Google OAuth.
  • It uploads the channel's own video files, titles, descriptions, tags, thumbnails and comments, and sets their publish time.
  • It reads the channel's own video list and view statistics (YouTube Data API and YouTube Analytics API) to plan posting times.

Where data is kept

The sign-in token and the saved view counts are stored only on the owner's own computer. Nothing is sent to any other server, sold, shared with third parties or used for advertising. The app does not collect data about viewers or any other person.

Psst Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access

Access can be removed at any time at Google Account → Third-party connections (or security.google.com/settings/security/permissions). Deleting the token file on the owner's computer also removes the stored sign-in.

Contact

Questions: use the contact details on the Psst Science YouTube channel.
